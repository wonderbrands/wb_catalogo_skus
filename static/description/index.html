Catálogo de productos WB

Gestión avanzada de Plantillas, Variantes y Productos Multicaja.

Funciones Principales

Este módulo es la aplicación central para visualizar y administrar el catálogo de productos de Wonderbrands. Sustituye la antigua versión de Odoo Studio por una solución nativa, más rápida y optimizada.

📦 Catálogo Centralizado

  • Acceso rápido a Plantillas de Producto.
  • Visualización directa de Variantes.

Filtros Avanzados

  • Filtro para detectar SKUs de tipo caja (#BOX).
  • Vistas limpias separando padres e hijos multicaja.
